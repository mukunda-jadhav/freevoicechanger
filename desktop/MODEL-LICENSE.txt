Female voice conversion model

IndicVoiceChanger, fine-tuned from Seed-VC for Indian-language voice conversion.
Model checkpoint: DreamSyncCo/IndicVoiceChanger, file
Indic-seed-uvit-tat-xlsr-tiny.pth. Its Hugging Face model card declares GPL-3.0.
https://huggingface.co/DreamSyncCo/IndicVoiceChanger

The application uses one female reference clip, s1p1.wav, from the public
Seed-VC demo examples. A public Seed-VC voice mapping labels s1p1 as female
and s1p2 as male. Source and attribution details are in
REFERENCE-VOICE-SOURCE.txt.

The model and reference clip are included for voice conversion. This is a
generic public reference voice, not a claim that it is a particular identifiable
speaker. See SEEDVC-LICENSE.txt and the model page for source and license details.
